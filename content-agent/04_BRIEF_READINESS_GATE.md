# 04 · Brief Readiness Gate — earn the right to write

Build `_work/brief.md`. **Writing the draft is forbidden until this gate is READY.** The brief
turns context + source pack into a plan the draft must follow.

## Required fields (every one filled)

```
Audience: <the specific ICP this piece is for>
Goal: <the one action/outcome this piece drives>
Format: <LinkedIn post | founder letter | landing block>   # v1 formats — short, not a 3000-word article
Angle: <the founder angle / opening that competitors miss>
Structure: <hook → ... → CTA, as bullets>
Must-mention: <2-4 facts from source_pack.md that MUST appear, by reference>
Forbidden: <claims/tones the claim-policy bans>
CTA: <the single call to action>
Success criteria: <how you'll know it worked — e.g. "5 qualified replies">
```

## Why so strict

A brief with no audience, no goal, no angle, or no CTA produces generic text. The agent treats any
empty field as a P0 — it would rather ask you than write blind.
